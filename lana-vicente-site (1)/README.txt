# Site da Lana Vicente — Massoterapeuta

Primeira versão do projeto para estudo e desenvolvimento.

## Como abrir
1. Baixe/descompacte a pasta.
2. Abra o arquivo `index.html` no navegador.
3. Edite `index.html` para os textos e `style.css` para o visual.
